2. **integration-guide.md**: Guide for integrating the UI library into projects
3. **component-api-guide.md**: API documentation for components

5. **implementation-plan.md**: Plan for implementing the UI library (includes roadmap)

9. **utilities-guide.md**: Documentation for utilities

These files are exported in `index.js` for easy access throughout the application.
